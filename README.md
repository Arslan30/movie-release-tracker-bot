# Movie Release Tracker Bot

Telegram bot for:

- Movie search
- TV search
- Track movies
- Track TV shows
- Movie release notifications
- Digital release notifications
- Blu-ray notifications
- TV episode notifications

## Features

- Posters
- Detailed movie information
- Detailed TV information
- Upcoming releases
- Upcoming episodes

## Setup

1. Create Telegram bot with BotFather
2. Get TMDB API key
3. Clone repository

git clone ...

4. Install requirements

pip install -r requirements.txt

5. Configure .env

BOT_TOKEN=
TMDB_API_KEY=

6. Run bot

python bot.py

7. Run notifications

python daily_check.py
